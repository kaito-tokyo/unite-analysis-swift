Verify a Unite Analysis release

These steps verify that a macOS disk image is the artifact attested by the Unite Analysis release workflow. They also verify its Apple Developer ID signature and notarization ticket.

Requirements

  • macOS 26 or later on Apple silicon
  • GitHub CLI
  • Xcode command-line tools

Download the latest disk image

Run these commands in an empty directory. The tag is read from the latest published GitHub Release. 

TAG="$(gh release view \
  --repo kaito-tokyo/unite-analysis-swift \
  --json tagName \
  --jq '.tagName')"
DISK_IMAGE="unite-analysis-swift-${TAG}-macos-arm64.dmg"

gh release download "$TAG" \
  --repo kaito-tokyo/unite-analysis-swift \
  --pattern "$DISK_IMAGE"

Verify the GitHub attestation

Release tags are signed annotated tags. Resolve the commit referenced by the tag, then require the attestation to match that commit, tag, and release workflow. 

TAG_OBJECT_SHA="$(gh api \
  "repos/kaito-tokyo/unite-analysis-swift/git/ref/tags/${TAG}" \
  --jq '.object.sha')"
SOURCE_SHA="$(gh api \
  "repos/kaito-tokyo/unite-analysis-swift/git/tags/${TAG_OBJECT_SHA}" \
  --jq '.object.sha')"

gh attestation verify "$DISK_IMAGE" \
  --repo kaito-tokyo/unite-analysis-swift \
  --signer-workflow \
    kaito-tokyo/unite-analysis-swift/.github/workflows/swift.yml \
  --source-ref "refs/tags/${TAG}" \
  --source-digest "$SOURCE_SHA" \
  --signer-digest "$SOURCE_SHA" \
  --deny-self-hosted-runners

Verify Apple signing and notarization

codesign --verify --strict --verbose=2 "$DISK_IMAGE"
codesign --display --verbose=4 "$DISK_IMAGE"
spctl --assess --verbose=4 --type open \
  --context context:primary-signature "$DISK_IMAGE"
xcrun stapler validate "$DISK_IMAGE"

Successful verification reports all of the following:

  • a Developer ID Application certificate issued by Apple;
  • a trusted Apple notarization result;
  • accepted from Gatekeeper; and
  • The validate action worked! from Stapler.

Install

After all verification commands succeed, open the disk image: 

open "$DISK_IMAGE"

Drag Kaito-Tokyo Unite Analysis.app onto the Applications shortcut to copy it into /Applications. To install only for the current user, copy the app into ~/Applications instead. Eject the disk image after copying. The CLI remains inside the app bundle; copying the app does not add it to PATH.
