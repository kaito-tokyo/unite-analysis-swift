Verify a Unite Analysis release

These steps verify that a macOS installer package is the artifact attested by the Unite Analysis release workflow. They also verify its Apple Developer ID signature and notarization ticket.

Requirements

  • macOS 26 or later on Apple silicon
  • GitHub CLI
  • Xcode command-line tools

Download the latest installer

Run these commands in an empty directory. The tag is read from the latest published GitHub Release. 

TAG="$(gh release view \
  --repo kaito-tokyo/unite-analysis-swift \
  --json tagName \
  --jq '.tagName')"
PACKAGE="unite-analysis-swift-${TAG}-macos-arm64.pkg"

gh release download "$TAG" \
  --repo kaito-tokyo/unite-analysis-swift \
  --pattern "$PACKAGE"

Verify the GitHub attestation

Release tags are signed annotated tags. Resolve the commit referenced by the tag, then require the attestation to match that commit, tag, and release workflow. 

TAG_OBJECT_SHA="$(gh api \
  "repos/kaito-tokyo/unite-analysis-swift/git/ref/tags/${TAG}" \
  --jq '.object.sha')"
SOURCE_SHA="$(gh api \
  "repos/kaito-tokyo/unite-analysis-swift/git/tags/${TAG_OBJECT_SHA}" \
  --jq '.object.sha')"

gh attestation verify "$PACKAGE" \
  --repo kaito-tokyo/unite-analysis-swift \
  --signer-workflow \
    kaito-tokyo/unite-analysis-swift/.github/workflows/swift.yml \
  --source-ref "refs/tags/${TAG}" \
  --source-digest "$SOURCE_SHA" \
  --signer-digest "$SOURCE_SHA" \
  --deny-self-hosted-runners

Verify Apple signing and notarization

pkgutil --check-signature "$PACKAGE"
spctl --assess --verbose=4 --type install "$PACKAGE"
xcrun stapler validate "$PACKAGE"

Successful verification reports all of the following:

  • a Developer ID Installer certificate issued by Apple;
  • a trusted Apple notarization result;
  • accepted from Gatekeeper; and
  • The validate action worked! from Stapler.

Install

After all verification commands succeed, open the package in Finder or install it for the current user: 

installer -pkg "$PACKAGE" -target CurrentUserHomeDirectory

This installs ~/Applications/Kaito-Tokyo Unite Analysis.app.
