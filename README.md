# unite-analysis-swift

A macOS command-line tool for extracting and analyzing evidence from
Pokémon Unite match recordings created by LDTX.

## Requirements

- macOS 26 or later on Apple Silicon

## Installation

1. Install the PKG from the latest release.
2. Ask your agent: Install the APM package from `kaito-tokyo/unite-analysis-swift#v0.2.2` globally.

## Skills

- **review-unite-matches-ja:** ユナイトレビュー
